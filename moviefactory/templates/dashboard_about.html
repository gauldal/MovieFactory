MovieFactory Hybrid Recommendation System

MovieFactory is a hybrid recommendation system that combines multiple independent retrieval engines into a unified decision pipeline. Rather than relying on a single algorithm, it integrates complementary signals to achieve more robust and explainable recommendations.

Hybrid Architecture Overview

The system aggregates results from four independent engines:

  • TF-IDF — Keyword-based lexical matching
  • SBERT — Semantic text embedding similarity
  • CLIP — Cross-modal image-text similarity
  • CF-SVD — Collaborative filtering via latent factors

Each engine produces a ranked signal. These signals are combined by a centralized Hybrid Engine that determines the final recommendation order.

Hybrid Weights Policy (v1)

In the current v1 implementation, hybrid weights are fixed in code to ensure deterministic behavior, reproducibility, and architectural stability.

The Dashboard does not modify runtime weights, and no configuration files are written during operation. All recommendations are generated using predefined, version-controlled weight presets.

Weight adjustment through a user interface is intentionally disabled in v1 and may be explored in a future experimental version.

Dashboard Scope

The Flask-based Dashboard provides a lightweight overview of the dataset and the hybrid recommendation system.

  • Dataset statistics overview
  • Recommendation analysis
  • System-level overview

Experimental analysis and operational monitoring are handled by a separate Streamlit analytics dashboard.

Analytical View (Streamlit)

The analytical dashboard is provided as a separate Streamlit application. It runs independently from the Flask service layer and operates in read-only mode. This separation avoids security and embedding constraints while keeping system responsibilities clear.
