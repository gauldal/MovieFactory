# Builder Manual

## 목적

빌더는 MovieFactory 프로젝트의 모든 산출물을
단일 원본 데이터로부터 생성하는 도구이다.

---

## 입력

- `movies_metadata_20000.csv`

---

## 산출물

빌더는 다음을 생성한다.

- `movie_clean_data_poster.csv`
- 검색 엔진 캐시(TF-IDF, SBERT, CLIP)
- 실행 가능한 코드 트리
- 서비스 실행에 필요한 파일 구조

---

## 실행 원칙

- 수작업 개입 없이 실행되어야 한다
- 동일한 입력은 항상 동일한 결과를 생성해야 한다
- 필수 산출물이 생성되지 않으면 빌더는 실패로 종료된다

---

## 실행 흐름

1. 원본 데이터 로드
2. 전처리 및 기준 데이터 생성
3. 캐시 생성
4. 코드 및 디렉토리 구성
5. 빌드 종료
